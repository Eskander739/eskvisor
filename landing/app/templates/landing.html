Управление виртуальными машинами

Работает сейчас: Создание, запуск, остановка, удаление ВМ через virt-install и libvirt API. Редактирование конфигураций, клонирование, полный жизненный цикл.

libvirt/KVM virt-install Hotplug

Управление хранилищами

Работает сейчас: Создание дисков (QCOW2, RAW, ISO), подключение/отключение к ВМ, LVM интеграция, конвертация форматов, мониторинг использования.

QCOW2/RAW LVM qemu-img

Виртуальные сети

Работает сейчас: NAT, bridge, isolated сети. DHCP, DNS, маршрутизация. Мониторинг подключенных ВМ, безопасное удаление.

NAT/Bridge DHCP/DNS Изоляция

Снапшоты и восстановление

Работает сейчас: Создание цепочек снапшотов, восстановление ВМ, клонирование из снапшота, управление метаданными, мониторинг размеров.

Цепочки Клонирование Восстановление

Контроль ресурсов через cgroups v2

Работает сейчас: Мгновенное ограничение CPU/RAM на уровне ядра Linux (1-5 мс). Предотвращение перерасхода ресурсов, гарантия доступности критических ВМ.

cgroups v2 Ядро Linux 1-5 мс

Бизнес-логика + системный контроль

Уникальное преимущество: Сочетание высокоуровневого контроля (пулы ресурсов, резервирование) с низкоуровневым ограничением через ядро. Предотвращение логических ошибок.
