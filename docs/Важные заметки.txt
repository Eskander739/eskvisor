1. Есть отключить диск у работающей ВМ(когда диска не существует) диск будет продолжаться читаться как ATTACHED пока мы не перезагрузим ВМ
Основные причины проблемы:
Libvirt кэширует информацию о ВМ

Состояние ВМ не обновляется автоматически после изменения конфигурации

XML дескриптор ВМ может быть закеширован

2. Если подключить диск, если он будет в состоянии ATTACHED но при этом перезагрузить ВМ - диск пропадет
3. Не работает detach с изменением только конфига для работающей ВМ
4. Для создания виртуальных дисков через библиотеку libvirt всегда нужен pool
