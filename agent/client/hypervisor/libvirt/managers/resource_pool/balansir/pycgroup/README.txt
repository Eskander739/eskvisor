Примерная схема cgroup директории:

/sys/fs/cgroup/                    # Корневая cgroup системы
├── system.slice/                  # Systemd системные службы
├── user.slice/                    # Пользовательские процессы
├── mypool_root/                   # ВАШ корень ресурсного пула (макс 2G RAM)
│   ├── app1/                      # Приложение 1 (макс 1G RAM)
│   └── app2/                      # Приложение 2 (макс 1G RAM)
└── other_apps/                    # Другие приложения


Визуализация наследования:
Корень (root) [memory.max = 10G]
    |
    ├── pool1 [memory.max = 5G] ← не может быть > 10G
    |       |
    |       └── container1 [memory.max = 2G] ← не может быть > 5G
    |
    └── pool2 [memory.max = 8G] ← не может быть > 10G

Дочерняя cgroup НЕ увеличивает общий лимит родителя

Дочерняя cgroup получает ПОДМНОЖЕСТВО ресурсов родителя

Сумма лимитов детей МОЖЕТ превысить лимит родителя (это важно!)
