## 🚀 Основные возможности

*   **Единый интерфейс управления:** Консольный клиент и REST API для управления ВМ на различных гипервизорах.
*   **Декларативная конфигурация:** Описание инфраструктуры в YAML-файлах с поддержкой шаблонов.
*   **Мощный CLI:** Полный набор команд для жизненного цикла виртуальных машин.
*   **Управление ресурсами:** Детальный контроль CPU, памяти, дисков и сетевых интерфейсов.
*   **Безопасность:** Изоляция сред, управление политиками доступа, аудит действий.
*   **Модульная архитектура:** Поддержка плагинов для расширения функциональности.
